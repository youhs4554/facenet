💡 OpenFace 3.0이란?

OpenFace 3.0은 얼굴의 다양한 정보를 동시에 분석하는 멀티 태스크 딥러닝 모델입니다.

  • 얼굴 감정 인식 (Emotion)
  • 액션 유닛 검출 (Action Units)
  • 얼굴 랜드마크 검출 (Landmarks)

Action Units (AU)란?

AU는 얼굴 근육의 움직임을 설명하는 시스템입니다. 값은 0(비활성)부터 1(최대 활성) 범위입니다.
